From now on, when someone messages our Telegram bot, keep them in the Members table of our Community base in Airtable: one row per Telegram user, keyed by their Telegram user id. Add the row the first time they write, and update it on every message after that. Each time, set their first name, their Telegram username, and the message they sent as their Last Message. If the message is /stop, set their Status to Unsubscribed; any other message sets it to Active.
